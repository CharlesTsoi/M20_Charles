# M20 机器狗外参标定

前后两台 RoboSense Airy 激光雷达的外参用实车 rosbag 核对过。前雷达作为基准，平移保持 CAD 值。后雷达的旋转改为各自雷达 IMU 求出的相对姿态。

标定日期：2026-10-29  
数据包：`rosbag2_2026_10_28-05_54_03`（时长 152.9 s）  
外参文件：`rslidar_ws/src/rslidar_sdk/config/config.yaml`

## 1. 结论

两台雷达的点云在录包时已经被驱动外参变到同一车体坐标系。各自用雷达内置 IMU 做 FAST-LIO 后，前后地图重合 98.7%，轨迹差平均 5.5 cm。x、y、z 以及前雷达的 roll、pitch、yaw 保持原值。

雷达 IMU 的重力在 −Y，车体点云的上方是 +Z。把这个固定轴向去掉以后，后雷达 IMU 相对前雷达 IMU 的车体旋转为：

- roll +0.047°
- pitch +0.999°
- yaw −0.029°

修正幅度 1.000°。这个旋转已经写入后雷达，替换原先由地面夹角得到的 roll −0.286°、pitch +0.573°、yaw 0°。

驱动的 pitch 在 −90° 附近。yaml 里后雷达的 roll、yaw 约为 ±2.70°，再叠加 pitch 从 −90.000° 到 −89.000°，合起来就是上面这一次 1.000° 车体旋转。安装位置没有转过 2.7°。

| 雷达 | 组播地址 | 话题 | x, y, z (m) | roll, pitch, yaw (rad) |
|---|---|---|---|---|
| 前 Airy | 224.10.10.201 | `/rslidar_points_front` | 0.32028, 0, -0.013 | 0, -1.570795, 3.1415926 |
| 后 Airy | 224.10.10.202 | `/rslidar_points_rear` | -0.32028, 0, -0.013 | 0.04712134, -1.55334372, -0.04763421 |

旋转顺序与 RoboSense 驱动一致：`R = Rz(yaw) * Ry(pitch) * Rx(roll)`。平移单位是米，角度单位是弧度。新旋转满足 `R_new = R_corr * R_old`，其中 `R_old` 是录包时的后雷达外参（roll 0、pitch −1.570795、yaw 0）。平移不变，旋转中心是后雷达原点。前雷达 yaw 为 π，后雷达在车体里仍朝后。

组播地址、端口和话题没有改。`224.10.10.201` 仍是前雷达，`224.10.10.202` 仍是后雷达。

## 2. 录包内容

驱动按 `config.yaml` 编译时打开了 `ENABLE_TRANSFORM`，录进包里的点云已经乘过录制当时的外参。这次写入的新后雷达角度只对下一次启动驱动后的实时点云生效，已录制的 bag 本身不变。两台雷达都是 RSAIRY，点云字段为 `x y z intensity ring timestamp`，约 10 Hz，96 线。

| 话题 | 类型 | 条数 | 说明 |
|---|---|---|---|
| `/rslidar_points_front` | PointCloud2 | 1528 | 前雷达，已做外参变换 |
| `/rslidar_points_rear` | PointCloud2 | 1528 | 后雷达，已做外参变换 |
| `/IMU` | Imu | 30585 | 车体 IMU，200 Hz，加速度单位 m/s²，静止时重力在 +Z |
| `/LIDAR/IMU201` | Imu | 30558 | 前雷达内置 IMU，单位约 g，重力在 −Y |
| `/LIDAR/IMU202` | Imu | 30558 | 后雷达内置 IMU，单位约 g，重力在 −Y |

三路 IMU 的角速度在时间上对齐，滞后为 0。点云头时间与雷达 IMU 使用同一套时钟。加速度约为 g 时，FAST-LIO 会按初始化阶段测到的重力模长归一到 9.81 m/s²。

## 3. 核对方法

单帧里两台半球雷达几乎没有公共视场，前雷达主要看见 +X，后雷达主要看见 −X。这段数据里车体走了约 19 m，并转了约 168°，两台雷达先后扫过同一片环境。

核对用各自的雷达 IMU，不用统一的 `/IMU`：

1. 前雷达点云配 `/LIDAR/IMU201`，后雷达点云配 `/LIDAR/IMU202`，分别跑 FAST-LIO。
2. 点云已经在车体坐标系。雷达 IMU 读到的重力沿 −Y，所以 FAST-LIO 的外参用固定轴向把车体 +Z 转到 IMU 的 −Y，平移用 CAD 的雷达原点。在线外参估计关闭。
3. 建图轨迹再变回初始车体坐标系，比较前后轨迹和两张地图。
4. 旋转外参单独由两路雷达 IMU 的角速度对齐得到。角速度大于 0.05 rad/s 的样本约 1.15 万个。前雷达保持录包时的驱动外参，后雷达写成与前雷达 IMU 的相对姿态。

FAST-LIO 使用 hku-mars 仓库的 `ROS2` 分支，工作空间在 `fast_lio_ws`。`lidar_type: 5`，使用点云里的绝对时间戳。

## 4. 结果

FAST-LIO，各保留 1525 / 1528 帧，单帧约 9 ms：

| 项目 | 前雷达 IMU201 | 后雷达 IMU202 |
|---|---|---|
| 轨迹长度 | 18.73 m | 18.94 m |
| 航向变化 | 168.0° | 168.8° |

变回车体坐标系后：

- 位姿差：平均 5.5 cm，90% 的帧小于 7.8 cm，最大 14.5 cm。平均偏差约 x +0.1 cm、y −2.4 cm、z +1.8 cm。
- 地图在 0.3 m 体素下的重合率：配准前 **98.7%**，配准后 **99.0%**。
- 把后雷达地图配到前雷达地图：yaw **−0.32°**，平移 **2.8 cm、2.4 cm、−0.9 cm**，配准均方距离 3.4 cm。

这些平移和配准 yaw 与里程计重复运行的散差同量级，所以 x、y、z 不改。写入的 yaw 只来自两路雷达 IMU 的相对姿态，为 −0.029°。

IMU 相对整数轴向的残余，车体坐标系：

| 雷达 | roll | pitch | yaw | 总角度 |
|---|---|---|---|---|
| 前 IMU201 | −0.73° | −1.10° | −0.11° | 1.31° |
| 后 IMU202 | −0.68° | −0.10° | −0.14° | 0.68° |
| 后相对前 | +0.047° | +0.999° | −0.029° | 1.000° |

后相对前的 1.000° 就是写入后雷达的车体修正。两路 IMU 互相之间的转角是 179.97°，对应前后雷达朝向相反。

## 5. 写入的外参

`config/config.yaml` 后雷达（组播 `224.10.10.202`，话题 `/rslidar_points_rear`）：

```yaml
x: -0.32028
y: 0.0
z: -0.013
roll: 0.04712134
pitch: -1.55334372
yaw: -0.04763421
```

前雷达保持：

```yaml
x: 0.32028
y: 0.0
z: -0.013
roll: 0.0
pitch: -1.570795
yaw: 3.1415926
```

用后雷达这三个角度反推回车体坐标系，得到 roll +0.0471°、pitch +0.9988°、yaw −0.0290°。

参数在驱动启动时从 yaml 读取。`ENABLE_TRANSFORM` 已经打开，这次只改角度，不必重新编译。重新启动 `rslidar_sdk` 后，新的后雷达旋转才会作用到实时组播点云上。

## 6. 复现

```bash
source /opt/ros/foxy/setup.bash
source ~/fast_lio_ws/install/setup.bash

# 前雷达，IMU 用 /LIDAR/IMU201
ros2 run fast_lio fastlio_mapping --ros-args \
  --params-file ~/M20外参标定/m20_front_lidar_imu.yaml
ros2 bag play ~/M20_bag/rosbag2_2026_10_28-05_54_03 \
  --topics /rslidar_points_front /LIDAR/IMU201

# 后雷达换成 m20_rear_lidar_imu.yaml，话题换成 /rslidar_points_rear 和 /LIDAR/IMU202
```

两份配置里 `extrinsic_est_en` 为 false。前雷达 `extrinsic_R` 为把车体 +Z 转到 IMU −Y 的轴向，`extrinsic_T` 为 `[0, -0.013, 0.32028]`。后雷达的 `extrinsic_R` 是同一轴向再绕竖轴转 180°。比较前要把 FAST-LIO 的 IMU 轨迹乘回车体坐标系。
